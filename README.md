# Premium Flip Clock Countdown

A clean, modern, and lightweight flip clock countdown built using semantic HTML5, modern CSS3 transitions, and vanilla JavaScript. 

## Features
- BEM architecture for styling
- Dynamic 3D card flipping effect
- Zero dependencies (Pure JS)

## How to Use
1. Clone or download this repository.
2. Open `index.html` directly in any browser.
3. To change the countdown duration, open `script.js` and modify the `endTime` logic.
